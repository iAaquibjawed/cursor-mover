# Code of Conduct

## The short version

Be decent to people. Assume the person on the other end is acting in good faith
and is short on time.

## Expected behaviour

- Keep discussion focused on the code and the problem.
- Accept that "no" is a valid answer. Cursor Mover is deliberately small, and
  most feature requests will be declined to keep it that way.
- Give people room to be wrong, including maintainers. Correct the fact and move
  on.

## Unacceptable behaviour

- Harassment, personal attacks, or demeaning comments about anyone.
- Discrimination or derogatory remarks relating to any personal characteristic.
- Publishing others' private information without permission.
- Sustained disruption of discussions, or pressuring maintainers for a response.

## Scope

This applies in issues, pull requests, discussions, commit messages, and any
other project space.

## Reporting

Report a problem privately to the maintainer via a
[GitHub security advisory](https://github.com/iAaquibjawed/cursor-mover/security/advisories/new),
which is the private channel this project has available. Reports are handled
confidentially.

Maintainers may edit, hide, or delete contributions, and may block accounts, in
response to behaviour that violates this document.

## Attribution

Adapted in spirit from the [Contributor Covenant](https://www.contributor-covenant.org),
shortened to suit a project of this size.
