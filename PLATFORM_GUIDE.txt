TO BUILD FOR OTHER PLATFORMS:
------------------------------

1. LINUX
--------
You need a Linux environment (VM, Docker, or remote server):

  Option A: Use Docker
  docker run --rm -v "$PWD":/src -w /src python:3.13 bash -c "
    pip install pyinstaller pyautogui pillow numpy &&
    pyinstaller --clean --noconfirm CursorMover-linux.spec &&
    tar -czf CursorMover-Linux.tar.gz -C dist CursorMover
  "

  Option B: On a Linux machine
  - Install: sudo apt-get install python3-tk xdotool
  - Build: pyinstaller CursorMover-linux.spec
  - Package: tar -czf CursorMover-Linux.tar.gz dist/CursorMover

  Output: CursorMover-Linux.tar.gz (~20 MB)


2. WINDOWS
----------
You need a Windows environment (VM or real machine):

  - Install: pip install pyinstaller pyautogui pillow numpy
  - Build: pyinstaller CursorMover-windows.spec
  - Package: Zip the CursorMover.exe file

  Output: CursorMover.exe or CursorMover-Windows.zip (~30 MB)


3. AUTOMATED BUILDS (RECOMMENDED)
----------------------------------
Set up GitHub Actions to build for all platforms automatically.

  File: .github/workflows/build.yml (see CROSS_PLATFORM_DISTRIBUTION.md)

  Benefits:
  - Build all platforms automatically
  - No need for VMs
  - Artifacts uploaded after each build
  - Free for public repos

WHAT USERS NEED FOR EACH PLATFORM:
-----------------------------------

macOS:

  - Accessibility permission

  - Python 3.8+ OR the executable
  - xdotool (sudo apt-get install xdotool)
  - Extract tar.gz → Run executable

Windows:
  - Windows 10+
  - May need to allow in Windows Defender
  - Extract zip → Run exe
