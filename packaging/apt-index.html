Cursor Mover — APT repository

Current version: __VERSION__ · amd64 · Debian, Ubuntu, and derivatives

Keep your computer awake by nudging the cursor. Add this repository once and you get updates through apt upgrade like any other package.

Install

sudo install -d -m 0755 /etc/apt/keyrings

curl -fsSL https://iaaquibjawed.github.io/cursor-mover/cursor-mover.asc \
  | sudo tee /etc/apt/keyrings/cursor-mover.asc > /dev/null

echo "deb [signed-by=/etc/apt/keyrings/cursor-mover.asc] https://iaaquibjawed.github.io/cursor-mover ./" \
  | sudo tee /etc/apt/sources.list.d/cursor-mover.list > /dev/null

sudo apt update
sudo apt install cursor-mover

Then launch Cursor Mover from your application menu, or run cursor-mover.

X11 only. Wayland does not permit applications to move the pointer, so Cursor Mover cannot work there. Check with echo $XDG_SESSION_TYPE — it must print x11.

Update and remove

sudo apt update && sudo apt upgrade cursor-mover
sudo apt remove cursor-mover

Prefer not to add a repository?

Download the .deb from the latest release and install it directly:

sudo apt install ./cursor-mover___VERSION__-1_amd64.deb
