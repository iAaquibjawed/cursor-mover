HOW TO DISTRIBUTE CURSORMOVER APP
==================================

YOUR READY-TO-SHARE FILE:
→ dist/CursorMover-macOS.dmg (25 MB)

This DMG is ready to share with users!


STEP 1: UPLOAD TO GITHUB RELEASES (Recommended)
------------------------------------------------
1. Push your code to GitHub (if not already)
2. Go to your GitHub repository
3. Click "Releases" → "Draft a new release"
4. Tag: v1.0.0
5. Title: CursorMover v1.0.0
6. Upload: dist/CursorMover-macOS.dmg
7. Add release notes (use template in DISTRIBUTION_GUIDE.md)
8. Publish


STEP 2: ALTERNATIVE - DIRECT SHARING
--------------------------------------
You can also share the DMG file via:
- Google Drive
- Dropbox
- Your website
- Email


STEP 3: USER INSTRUCTIONS
--------------------------
Send this to users:

"To install CursorMover:
1. Download CursorMover-macOS.dmg
2. Open the DMG
3. Drag CursorMover.app to Applications
4. Launch CursorMover from Applications
5. When prompted, grant accessibility permission
6. Click 'Start' to begin

If you see 'App is damaged':
- Right-click the app → Open (first time only)

For help, visit: https://github.com/yourusername/cursor-mover"


STEP 4: TEST IT FIRST!
----------------------
Before sharing:
1. Mount the DMG
2. Install CursorMover.app to Applications
3. Run it
4. Verify it works
5. Test permissions workflow
